# Assets Directory

This folder is configured for external assets (images, audio, fonts).
By default, **TURBO APEX** uses high-performance procedural rendering and synthesized audio generated in real time using Pygame and NumPy.

If you wish to substitute external images or sounds, you may place them here:
- `cars/`: Vehicle sprites
- `environment/`: Background textures or roadside sprites
- `fonts/`: TTF fonts
- `sounds/`: WAV / OGG sound effects
